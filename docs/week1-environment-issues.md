## 몬스터

### #M1 기본 몬스터 — 근거리 공격 AI + HP + 드랍

**설명**
1주차의 유일한 적 종류. 플레이어를 추적해 근접 시 공격, 사망 시 경험치/골드 드랍.

**작업 내용**
- [ ] Monster prefab (Animator, NavMeshAgent 또는 단순 추적 스크립트)
- [ ] HP 시스템 (`TakeDamage`, `OnDeath`) — 캐릭터의 `HealthSystem`과 공통 베이스 검토 (`IDamageable` 인터페이스)
- [ ] 근접 거리 도달 시 공격 모션 → OverlapSphere/콜라이더로 플레이어 데미지
- [ ] 사망 시 경험치/골드 드랍 → `ExperienceSystem.AddExp()` 호출
- [ ] 드랍 양·HP·공격력은 `MonsterData` (ScriptableObject)로 분리
- [ ] 피격 시 짧은 경직(hitstun) — 없으면 공격이 안 박히는 느낌

**완료 조건**
- 플레이어 접근 시 추적 → 공격, 처치 시 경험치 게이지 증가.
- Inspector에서 `MonsterData` 값 바꾸면 즉시 반영.

**의존**: 캐릭터 #4 (HP/스테미나), 캐릭터 #5 (공격이 데미지 주려면), 캐릭터 #8 (경험치)
**라벨**: `monster`, `week-1`

## 보스

### #B1 보스 — 추적 + 기본공격 (1주차 버전)

**설명**
5웨이브 클리어 후 등장. 1주차는 단순 AI(추적 + 근접 기본공격)만. 스킬(즉사 돌진/원거리 스턴/폭탄)은 2주차.

**작업 내용**
- [ ] Boss prefab (몬스터보다 큰 스케일, Animator, 추적 스크립트)
- [ ] HP 시스템 (몬스터보다 훨씬 높게, `BossData` SO로 분리)
- [ ] 추적 행동: 플레이어 위치로 이동
- [ ] 근접 거리 도달 시 기본공격 모션 + 데미지
- [ ] 보스 등장 트리거 — `WaveManager`에서 호출
- [ ] 보스 사망 → `OnGameClear` 이벤트 (디버그 메시지/클리어 텍스트로 충분)

**완료 조건**
- 보스가 등장해서 플레이어를 쫓아오고, 근접 시 공격.
- 보스 처치 시 클리어 화면(임시 텍스트) 표시.

**의존**: 캐릭터 #4, 캐릭터 #5, #S1, #S2
**라벨**: `boss`, `week-1`

## 맵 & 웨이브

### #S1 맵 제작 — 단일 맵 + 스폰 포인트

**설명**
단일 맵에서 모든 진행. 1주차는 기본 지형 + 경계 + 스폰 포인트만. 상점/포탈/저장 오브젝트 자리는 비워두고 2주차에 채움.

**작업 내용**
- [ ] 기본 지형 (Plane 또는 단순 폴리곤 메쉬)
- [ ] 벽/장애물 콜라이더 — 맵 밖으로 못 나가게
- [ ] 플레이어 시작 지점 마커
- [ ] 몬스터 스폰 포인트 4~6개 분산 배치 (빈 GameObject + 기즈모)
- [ ] 보스 등장 지점
- [ ] **2주차 슬롯 표시만** — 상점/포탈/저장 오브젝트 위치는 빈 GameObject로 표시만

**완료 조건**
- 플레이어가 맵 안에서 자유롭게 움직이고 밖으로는 못 나감.
- Scene 뷰에서 스폰 포인트 기즈모로 확인 가능.

**의존**: 캐릭터 #1
**라벨**: `map`, `week-1`

### #S2 웨이브 매니저 — 5웨이브 구성 + 클리어 판정

**설명**
5웨이브 자동 진행. 각 웨이브마다 정해진 수의 몬스터 스폰, 모두 처치 시 다음 웨이브. 5웨이브 후 보스 등장.

**작업 내용**
- [ ] `WaveManager` (싱글톤 또는 씬 매니저 GO)
- [ ] `WaveData` (ScriptableObject) — 몬스터 수, 종류, 스폰 간격
- [ ] 웨이브 시작 → 스폰 포인트에서 몬스터 출현
- [ ] 살아있는 몬스터 카운트 → 0이면 웨이브 클리어
- [ ] 웨이브 간 인터벌 (3~5초)
- [ ] 5웨이브 클리어 후 보스 스폰
- [ ] 현재 웨이브 / 남은 몬스터 수 표시 UI (단순 텍스트로 충분)

**완료 조건**
- 게임 시작 → 웨이브 1~5 자동 진행 → 보스 등장 → 처치 시 클리어 텍스트.

**의존**: #M1, #B1, #S1
**라벨**: `wave`, `week-1`

## 1주차 전체 의존성 (캐릭터 포함)

```
[캐릭터 라인]
 #1 컨트롤러 → #2 InputSystem ┐
              ↘ #3 스텟       │
              ↘ #4 HP/스테    │
              ↘ #5 기본공격   │
              ↘ #6 강공       │
              ↘ #7 회피       │
              ↘ #8 경험치/UI ─┤
                              │
[환경/콘텐츠 라인]             │
 #S1 맵 ─┬──────────────────→ #S2 웨이브 → #BUILD1
 #M1 몬스터(의존: #4, #5, #8) ┘    ↑
 #B1 보스(의존: #4, #5, #S1) ─────┘
```

캐릭터 #5(기본공격)까지 굴러가면 #M1·#B1 작업 시작 가능 → 4~5번 이슈 끝나는 시점부터 환경 라인을 병행하면 1주차 안에 빌드까지 가능.
