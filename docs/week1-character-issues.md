**설명**
캐릭터 prefab을 씬에 배치하고 WASD 이동, 카메라 추적, Animator 기본 상태(Idle/Run)까지 연결한다. 이후 모든 전투 작업의 토대가 되는 이슈.

**작업 내용**
- [ ] 임포트한 캐릭터 에셋으로 Player prefab 구성 (Rigidbody, Collider, Animator)
- [ ] WASD 이동 (속도값은 임시 상수, 후에 스텟 시스템에서 가져오게 리팩토링)

**완료 조건**

## #3 캐릭터 스텟 시스템 (ScriptableObject 기반)

**설명**
힘 / 민첩 / 체력 / 스테미나 4종 기본 스텟을 ScriptableObject로 정의하고, 런타임에서 변경 가능한 `PlayerStats` 컴포넌트와 분리. 포폴 어필 포인트.

**작업 내용**
- [ ] `CharacterStatData` (ScriptableObject) — 기본 스텟 + 성장계수
- [ ] `PlayerStats` (MonoBehaviour) — 런타임 현재값, 레벨업 시 증가, 이벤트 노출 (`OnStatChanged`)
- [ ] 스텟 → 실제 수치 변환 공식 정의
  - 힘 → 공격력 배율
  - 민첩 → 이동속도 / 공격속도
  - 체력 → 최대 HP
  - 스테미나 → 최대 스테미나 + 회복속도
- [ ] 이동 스크립트에서 이속을 `PlayerStats`에서 가져오도록 연결

**완료 조건**
- Inspector에서 ScriptableObject 값 바꾸면 게임 플레이에 반영됨.
- 다른 시스템(HP, 데미지)이 `PlayerStats`만 참조하면 됨.

**의존**: #1

## #4 HP / 스테미나 시스템 + UI 게이지

**설명**
HP와 스테미나의 현재값/최대값을 관리하고, 화면 상단에 게이지를 표시한다. 스테미나는 후속 공격/회피 이슈들이 의존하는 핵심 자원.

**작업 내용**
- [ ] `HealthSystem` — 현재 HP, 최대 HP, `TakeDamage()`, `OnDeath` 이벤트
- [ ] `StaminaSystem` — 현재 스테미나, 최대 스테미나, `TryConsume(amount)` (실패 시 false 리턴), `Recover(amount)`
- [ ] 스테미나 자연 회복은 일단 **OFF** (기본공격 시에만 회복, 기획에 맞춤)
- [ ] HP 바 + 스테미나 바 UI (Canvas, Image fillAmount)
- [ ] 두 시스템 모두 `PlayerStats` 변화 구독해서 최대값 갱신

**완료 조건**
- Inspector 버튼/디버그 키로 데미지/스테미나 소모 테스트 시 UI가 즉시 반영됨.
- 스테미나 0일 때 `TryConsume`이 false 리턴.

**의존**: #3

## #5 좌클릭 기본공격 3타 콤보

**설명**
좌클릭 입력을 받아 3타까지 이어지는 콤보 공격. 콤보 윈도우 내 재입력 시 다음 타로, 윈도우 놓치면 콤보 리셋. 기본공격은 **스테미나 회복**.

**작업 내용**
- [ ] Animator에 Attack1 / Attack2 / Attack3 상태 + 트리거 파라미터
- [ ] `PlayerCombat` 스크립트 — 콤보 인덱스 관리, 입력 큐잉
- [ ] 콤보 윈도우(예: 애니메이션 후반 30%)에서만 다음 타 입력 허용
- [ ] 각 타 종료 시 스테미나 +N 회복 (수치는 임시값, 후에 밸런싱)
- [ ] 히트박스 / OverlapSphere로 적 탐지 (실제 데미지 적용은 #8 또는 몬스터 이슈에서)
- [ ] 공격 중 이동속도 감소 / 락 결정

**완료 조건**
- 좌클릭 연타 시 3타까지 자연스럽게 이어지고, 3타 후 또는 윈도우 놓치면 1타로 리셋.
- 한 타 끝날 때마다 스테미나 게이지가 차오름.

**의존**: #2, #3, #4

## #6 우클릭 강공 2타 (스테미나 소모만)

**설명**
우클릭 강공 2타. **쿨타임 없이 스테미나 소모만으로 제한**한다. 모션 후딜과 스테미나 잔량이 자연스러운 페이싱 역할.

**작업 내용**
- [ ] `HeavyAttack1` / `HeavyAttack2` Animator 상태 + 트리거
- [ ] 강공 입력 시: 스테미나 충분한지 확인 → 소모 후 시전 (부족 시 발동 안 함)
- [ ] 강공 1타 → 2타 콤보 윈도우 연결 (기본공격과 동일 패턴)
- [ ] 기본공격 중간에 강공으로 캔슬 가능한지 규칙 결정 (권장: 기본 → 강공 캔슬 OK, 강공 → 기본공격 캔슬 불가)
- [ ] 강공 1회당 스테미나 소모량은 기본공격 1타 회복량보다 충분히 크게 (임시값으로 시작, 후 밸런싱)

**완료 조건**
- 우클릭으로 2타 강공이 나감.
- 스테미나 부족 시 발동 안 됨 (UI/효과음 피드백은 후순위).
- 모션 중에는 자연스럽게 다음 입력이 막혀서 스팸이 불가능함.

**의존**: #2, #4, #5

## #7 회피 (Dodge, Space) + i-frame + 쿨타임 헬퍼

**설명**
짧은 거리 회피 이동 + 무적 프레임. 스테미나 단발 소모 + 짧은 쿨타임(0.3~0.5초)로 스팸 방지. 회피가 처음으로 쿨타임을 쓰는 시스템이라, 여기서 재사용 가능한 `Cooldown` 헬퍼도 함께 만들어 이후 스킬 이슈에서 재활용.

**작업 내용**
- [ ] 재사용 가능한 `Cooldown` 헬퍼 (남은 시간, `IsReady`, `Start()`) — Q/Shift+Q 등 스킬에서 재사용
- [ ] `Dodge` 입력 처리 — 쿨타임/스테미나 체크
- [ ] 회피 방향 결정: 입력 방향이 있으면 그쪽, 없으면 캐릭터 정면 (또는 후면, 게임 톤에 맞춰 결정)
- [ ] DOTween 또는 Rigidbody force / CharacterController.Move로 짧은 거리 이동
- [ ] 회피 모션 Animator 상태 추가, 회피 중 다른 입력 잠금 (또는 후반부 캔슬 허용)
- [ ] **i-frame**: 회피 시작 ~ N프레임 동안 `HealthSystem.IsInvincible = true`
- [ ] 회피 후 짧은 쿨타임 적용 (0.3~0.5초)

**완료 조건**
- Space로 회피 가능, i-frame 동안 데미지 받지 않음(디버그로 확인).
- 스테미나 부족하거나 쿨타임 중에는 회피 불가.
- `Cooldown` 헬퍼는 단독으로도 테스트 가능 (간단한 단위 테스트 또는 디버그 인스펙터).

**의존**: #2, #4
